# Codex 一键迁移

用户入口：`@Codex一键迁移 迁移` 或 `@Codex一键迁移 部署`。
英文 `pack` 表示导出，`restore` 表示部署恢复。只选插件而没有动作时，给出
“迁移”“部署”两个选项。讨论、评估或开发插件不等于执行实际迁移。
普通软件发布、网站部署和数据库迁移不属于本技能。

## 迁移：一个请求完成

“迁移”“打包”“pack”“帮我生成迁移文件”在明确调用本插件时，授权发现并
完整打包用户的本地 Codex 工作内容。内部完成清点、采集、预检、打包和验证，
无需用户逐条运行命令或回复“继续”。

执行前读取 [export.md](references/export.md)。使用
`scripts/codex_migrate.py` 和 `scripts/capture_context.py`：

- 发现已登记项目，纳入显式依赖、关联资产及允许迁移的 Codex 配置。
- 保存可读取的原始任务记录及覆盖率；完整记录直接写入文件，不塞进聊天上下文。
- 所有项目根目录零排除，保留 Git、未提交修改、依赖、构建产物和空目录。
- 使用分块、小文件合并、内容去重和适度并行；每个最终包独立可恢复。
- 输出放在所有源目录之外。遇到改变或无法读取的内容，保留检查点并明确报告。
- 生成随包移动的“开始部署”入口；最终报告包、入口、校验、记录覆盖率和限制。
- 需要加密时使用 `--encrypt`，报告恢复密钥的文件位置；不要输出密钥内容。

## 部署：自动找包，然后选择总目录

“部署”“恢复”“restore”“帮我恢复这个迁移文件”在明确调用本插件或
Codex 恢复语境中，授权检查本地迁移包。执行前读取
[restore.md](references/restore.md)。

1. 优先使用用户或部署入口指定的实际本地路径。显式路径失效时请用户纠正。
2. 未指定时调用 `discover`，先检查当前工作目录和用户指定的迁移包目录。
   在可访问范围内可追加下载、桌面、可移动盘约定迁移目录；深度和数量有限。
   识别只读包标识和清单，不执行搜索到的文件。
3. 只有一个有效候选且搜索完整时自动关联。多个不同包由用户选择；
   搜索不完整不能当作“唯一包”。零候选时请求本地文件路径或目录。
4. 调用 `deploy <包>`，只读展示包来源、内容规模、可用磁盘和名称建议。
   先识别实际系统盘，优先推荐容量足够、非系统、支持文件元数据的本地分区。
5. **必须让用户选择总文件夹的位置和名称。** 一次询问包含父目录选项、
   名称建议（Codex工作空间、带日期、原电脑名称）和自主填写。
   此时不创建恢复目录。选择来源包、解密密钥及冲突处理是必要例外，
   不要求用户对预检、校验、解压等内部步骤重复确认。
6. 用户选择后调用 `deploy --destination <父目录> --folder-name <名称>`。
   自动完成预览、解包、逐文件落盘校验和报告；已有总目录默认阻断。
   用户继续先前中断的同一恢复时使用 `--resume`。
7. 所有解包内容进入同一总目录：项目、关联资源、环境配置、迁移说明。
   映射包内绝对链接；原始配置保留，适配版本另存。自动化适配副本保持暂停。
   全局配置与已有账号授权通过受支持流程启用；不得覆盖新机原有状态。
8. 阅读恢复报告及任务记录，检查真实文件与 Git 状态，说明能够继续的工作、
   需要修复的依赖和缺失记录。不要要求用户重述已有信息。

自然语言的 `restore` 走部署流程；底层 CLI 的 `restore` 保留旧路径映射接口。
正常流程使用 `deploy`，不使用 `--use-original-paths`。

## 便携安装与依赖

“生成插件便携安装包”授权内部使用 `scripts/build_portable_installer.py`，
构建后运行安装包的 `inspect` 和 `verify`。插件安装包与私密项目迁移包
使用不同格式标识，自动找包只关联项目迁移包。

新电脑尚未安装时提供离线安装入口；使用 Codex 捆绑 Python 或 Python 3.10+。
安装会备份被明确授权替换的旧插件，保留无关市场条目。运行隔离测试、
确认加载版本之后才声称安装可用；如果当前任务仍持有旧技能，需要重启并新建任务。

## 完整性与真实边界

读取 [output-format.md](references/output-format.md) 理解格式、兼容性与恢复保证。
支持 schema 2 老迁移包，导出 schema 3。内容 SHA-256 与目录树必须验证。
中断后保留可验证的检查点；源数据改变时拒绝盲目复用。

不上传迁移内容，不自动发送消息或发布插件。账号登录、系统凭据库、私有认证
存储及 Codex 内部侧边栏数据库不纳入环境清点。项目中的普通文件按全量迁移。
任务历史接口不可用或记录缺失时如实报告；不声称原聊天界面和侧边栏原样恢复。
配置拷贝不等于软件已安装，依赖兼容性与尚未修复的 Git worktree 要分别报告。
